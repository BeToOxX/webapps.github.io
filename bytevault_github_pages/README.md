# ByteVault Web Security Lab - Documentación

El archivo principal para GitHub Pages es `index.md`.

## Publicar con GitHub Pages

1. Sube estos archivos a un repositorio de GitHub.
2. Ve a **Settings > Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main`.
5. Selecciona la carpeta `/ (root)`.
6. Guarda.
7. Espera a que GitHub genere la URL.

Ejemplo:

`https://TU-USUARIO.github.io/NOMBRE-REPOSITORIO/`

## Capturas

Coloca las imágenes dentro de:

`assets/img/`

Los nombres de archivo esperados ya aparecen dentro de `index.md`.
