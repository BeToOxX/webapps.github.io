# Glosario

En esta sección se describen las principales siglas y conceptos relacionados con seguridad web utilizados dentro de la documentación.

| Sigla / término | Significado | Descripción |
|---|---|---|
| **API** | Application Programming Interface | Interfaz que permite la comunicación entre diferentes aplicaciones o servicios. |
| **CIA** | Confidentiality, Integrity and Availability | Modelo compuesto por confidencialidad, integridad y disponibilidad. |
| **CORS** | Cross-Origin Resource Sharing | Mecanismo utilizado por los navegadores para controlar solicitudes realizadas entre diferentes orígenes. |
| **CSP** | Content Security Policy | Política de seguridad que restringe los recursos y scripts que una página puede ejecutar. |
| **CSRF** | Cross-Site Request Forgery | Ataque que intenta realizar acciones utilizando la sesión autenticada de un usuario. |
| **CVE** | Common Vulnerabilities and Exposures | Sistema utilizado para identificar públicamente vulnerabilidades conocidas. |
| **CVSS** | Common Vulnerability Scoring System | Sistema utilizado para asignar un nivel de gravedad a una vulnerabilidad. |
| **CWE** | Common Weakness Enumeration | Catálogo de debilidades comunes que pueden existir en software. |
| **DDoS** | Distributed Denial of Service | Ataque distribuido cuyo objetivo es afectar la disponibilidad de un servicio. |
| **DoS** | Denial of Service | Ataque destinado a impedir el funcionamiento normal de un sistema o servicio. |
| **DOM** | Document Object Model | Representación estructurada de los elementos de una página web utilizada por los navegadores. |
| **HTTP** | Hypertext Transfer Protocol | Protocolo utilizado para transmitir información entre clientes y servidores web. |
| **HTTPS** | Hypertext Transfer Protocol Secure | Versión de HTTP protegida mediante cifrado TLS. |
| **IDOR** | Insecure Direct Object Reference | Vulnerabilidad donde un usuario puede acceder a recursos sin la autorización correspondiente mediante la manipulación de identificadores. |
| **JWT** | JSON Web Token | Formato utilizado para transmitir información firmada entre diferentes componentes de una aplicación. |
| **LFI** | Local File Inclusion | Vulnerabilidad que puede permitir incluir o acceder a archivos locales del servidor. |
| **MFA** | Multi-Factor Authentication | Autenticación que requiere más de un método de verificación. |
| **OWASP** | Open Worldwide Application Security Project | Organización internacional dedicada a mejorar la seguridad del software. |
| **RCE** | Remote Code Execution | Vulnerabilidad que puede permitir la ejecución remota de código en un sistema. |
| **REST** | Representational State Transfer | Estilo arquitectónico utilizado frecuentemente para desarrollar servicios web y APIs. |
| **RFI** | Remote File Inclusion | Vulnerabilidad relacionada con la inclusión de archivos externos en una aplicación. |
| **SQL** | Structured Query Language | Lenguaje utilizado para interactuar con bases de datos relacionales. |
| **SQLi** | SQL Injection | Vulnerabilidad en la que entradas manipuladas pueden modificar el comportamiento de una consulta SQL. |
| **SSR** | Server-Side Rendering | Técnica en la cual el servidor genera el contenido HTML antes de enviarlo al navegador. |
| **SSRF** | Server-Side Request Forgery | Vulnerabilidad que puede provocar que un servidor realice solicitudes hacia recursos no autorizados. |
| **SSTI** | Server-Side Template Injection | Vulnerabilidad en la que una entrada puede ser interpretada por un motor de plantillas del servidor. |
| **TLS** | Transport Layer Security | Protocolo utilizado para proteger comunicaciones mediante cifrado. |
| **URL** | Uniform Resource Locator | Dirección utilizada para identificar un recurso disponible en una red. |
| **WAF** | Web Application Firewall | Firewall especializado en analizar y filtrar tráfico dirigido a aplicaciones web. |
| **XSS** | Cross-Site Scripting | Vulnerabilidad que permite introducir contenido que puede ser interpretado como código por el navegador. |
| **Stored XSS** | Stored Cross-Site Scripting | Variante de XSS en la que el contenido malicioso queda almacenado en la aplicación. |
| **ZAP** | Zed Attack Proxy | Herramienta de OWASP destinada al análisis de seguridad de aplicaciones web. |
