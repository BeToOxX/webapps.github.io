# Glosario

| Sigla / término | Significado | Descripción |
|---|---|---|
| **API** | Application Programming Interface | Interfaz que permite la comunicación entre aplicaciones o servicios. |
| **CIA** | Confidentiality, Integrity and Availability | Modelo de seguridad compuesto por confidencialidad, integridad y disponibilidad. |
| **CORS** | Cross-Origin Resource Sharing | Mecanismo que controla solicitudes realizadas entre orígenes distintos. |
| **CSP** | Content Security Policy | Política que restringe los recursos y scripts que una página puede ejecutar. |
| **CSRF** | Cross-Site Request Forgery | Ataque que intenta ejecutar acciones aprovechando la sesión autenticada de un usuario. |
| **CVE** | Common Vulnerabilities and Exposures | Sistema de identificación pública de vulnerabilidades conocidas. |
| **CVSS** | Common Vulnerability Scoring System | Sistema utilizado para valorar la gravedad de una vulnerabilidad. |
| **CWE** | Common Weakness Enumeration | Catálogo de debilidades comunes presentes en software. |
| **DDoS** | Distributed Denial of Service | Ataque distribuido orientado a afectar la disponibilidad de un servicio. |
| **DoS** | Denial of Service | Ataque orientado a impedir el funcionamiento normal de un servicio. |
| **DOM** | Document Object Model | Representación estructurada de los elementos de una página web. |
| **HTML** | HyperText Markup Language | Lenguaje de marcado utilizado para estructurar páginas web. |
| **HTTP** | Hypertext Transfer Protocol | Protocolo utilizado para la comunicación entre clientes y servidores web. |
| **HTTPS** | Hypertext Transfer Protocol Secure | Versión de HTTP protegida mediante cifrado TLS. |
| **IDOR** | Insecure Direct Object Reference | Falla de control de acceso donde se manipulan identificadores para acceder a recursos no autorizados. |
| **JWT** | JSON Web Token | Formato utilizado para transmitir información firmada entre sistemas. |
| **LFI** | Local File Inclusion | Vulnerabilidad que puede permitir incluir o acceder a archivos locales del servidor. |
| **MFA** | Multi-Factor Authentication | Autenticación que requiere más de un factor de verificación. |
| **OWASP** | Open Worldwide Application Security Project | Organización internacional enfocada en mejorar la seguridad del software. |
| **RCE** | Remote Code Execution | Vulnerabilidad que puede permitir la ejecución remota de código. |
| **REST** | Representational State Transfer | Estilo arquitectónico utilizado habitualmente en servicios web y APIs. |
| **RFI** | Remote File Inclusion | Vulnerabilidad relacionada con la inclusión de archivos remotos. |
| **SQL** | Structured Query Language | Lenguaje utilizado para consultar y administrar bases de datos relacionales. |
| **SQLi** | SQL Injection | Vulnerabilidad que permite alterar una consulta SQL mediante entradas manipuladas. |
| **SSR** | Server-Side Rendering | Técnica en la que el servidor genera HTML antes de enviarlo al navegador. |
| **SSRF** | Server-Side Request Forgery | Vulnerabilidad que provoca que un servidor realice solicitudes no autorizadas. |
| **SSTI** | Server-Side Template Injection | Vulnerabilidad donde entradas son interpretadas por un motor de plantillas del servidor. |
| **TLS** | Transport Layer Security | Protocolo criptográfico utilizado para proteger comunicaciones. |
| **URL** | Uniform Resource Locator | Dirección utilizada para identificar un recurso en una red. |
| **WAF** | Web Application Firewall | Firewall especializado en proteger aplicaciones web. |
| **WSL** | Windows Subsystem for Linux | Funcionalidad de Windows para ejecutar entornos Linux. |
| **XSS** | Cross-Site Scripting | Vulnerabilidad que permite introducir contenido interpretado como código por el navegador. |
| **Stored XSS** | Stored Cross-Site Scripting | Variante de XSS donde el contenido malicioso queda almacenado en la aplicación. |
| **ZAP** | Zed Attack Proxy | Herramienta de OWASP para analizar la seguridad de aplicaciones web. |
